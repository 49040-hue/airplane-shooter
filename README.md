# 2D Airplane Shooter (Unity 6)

A 2D airplane shooting game for Unity 6 (URP / new Input System).
All art (sprites, explosion animation) is generated by an editor script, so no assets are needed.

## Features
- Move in all directions (WASD / Arrows / gamepad)
- Bullets (Space) and homing missiles (M)
- Enemy spawning with 3 enemy types (Scout, Gunship, Interceptor)
- Explosion animation (Unity Animator)
- Health bar, score and high score
- 3 stages, then a Boss fight

## How to use
1. Copy the `Assets/AirplaneGame` folder into any Unity 6 project (Active Input Handling: `Both` or `Input System Package`).
2. Wait for compile, then choose **Tools > Build Airplane Game**.
3. Press **Play**.

Controls: `WASD`/Arrows = move, `Space` = bullets, `M` = missile, `R` = restart.
